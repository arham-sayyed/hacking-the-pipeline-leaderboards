## How to submit a flag

1. Go to the **Issues** tab above.
2. Click **New Issue**.
3. Pick the template matching the cycle you just solved.
4. Paste your flag exactly as found, submit.
5. A bot checks it within a few seconds. Correct answers close automatically
   and you'll see your solve rank in the comment. Wrong answers get a comment too. edit the same issue to try again, no need to open a new one.
